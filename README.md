# 讀書計畫課程示範

這是一個可放在 GitHub Pages 的最小讀書平台。入口是 `index.html`，不需安裝套件或建置。教材、計畫、測驗記錄存在使用者瀏覽器的 `localStorage`；換裝置或清除瀏覽器資料後不會同步。`ref/` 是本機課堂參考資料，已加入 `.gitignore`，不會隨公開網站發布。

## 草稿功能如何操作

| 草稿構想 | 示範操作 |
| --- | --- |
| Notion、課本、講義、掃描筆記 | 在「建立計畫」貼入重點文字，來源網址可選填；掃描件需先整理或 OCR 成文字 |
| AI 根據教材與時間排課程 | 輸入主題、重點、每日分鐘數和一週天數，按「產生本週計畫」；目前排程是固定規則，AI 用於出題 |
| 週課表、Google Calendar | 在「每週安排」看任務，下載 `.ics` 再到 Google Calendar 匯入；沒有直接寫入 Google 帳號 |
| 自動生成測驗、錯題重複複習 | 「練習測驗」可做筆記自我檢查；貼自己的 Gemini 金鑰可產生 3 題；按「待複習」後，該筆記題下次會排在前面 |
| 學習進度、家長可看進度 | 勾選任務與記錄答題後，到「學習進度」查看學生和家長／老師摘要；目前只能在同一台裝置查看 |

## GitHub Pages

將此儲存庫推到 GitHub 後，到 **Settings → Pages → Build and deployment**，選 **Deploy from a branch**、`main`、`/ (root)`。發布網址通常是 `https://<帳號>.github.io/ClaudeClass/`。直接開啟本機 `index.html` 也可以測試不用 AI 的功能。

## 學生自備 Gemini API 金鑰

學生到 [Google AI Studio 的 API Keys 頁面](https://aistudio.google.com/api-keys) 建立自己的金鑰，在網站「練習測驗」欄位貼上，按「用我的教材產生 3 題」。此版直接由學生瀏覽器呼叫 `gemini-2.5-flash`，**不需要 Google Apps Script**，老師也不用提供自己的金鑰。金鑰沒有寫進程式碼，也不會存入 `localStorage`；重新整理或關閉頁面就要重新貼。網站使用者自己的教材重點會直接送到 Gemini API。

每把金鑰都屬於一個 Google 專案，額度和計費依該專案的方案而定。免費方案在額度內不收費，達到限制後可能暫時不能呼叫；只有學生自行啟用付費方案時，才會依該專案的計費設定付費。不是「貼上金鑰就一定會付錢」。可以在 AI Studio 查看自己的使用量與方案。

**課堂示範限制：** 因為呼叫從瀏覽器發出，學生自己的金鑰會出現在自己瀏覽器的網路請求中，瀏覽器擴充功能或共用電腦也可能接觸到。Google 建議正式產品使用伺服器端代理保護金鑰；此版只適合明確告知風險的課堂原型。不要在共用電腦使用付費金鑰，不要把金鑰交給老師或其他學生；懷疑外洩時到 AI Studio 停用／更換金鑰。若要讓家長從其他裝置登入、同步進度或讓 AI 排完整課程，還需要帳號、資料庫與伺服器端設計。

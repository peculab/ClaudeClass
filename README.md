# ClaudeClass｜讀書計畫課程示範

ClaudeClass 是依學生讀書平台草稿製作的最小可操作原型。學生貼入教材重點與可用時間，網站產生讀書任務，提供自我檢查、Gemini 出題、待複習標記和進度摘要。它是純靜態網站，可發布到 GitHub Pages，不需安裝套件、資料庫或 Google Apps Script。

> 快速試用：將 [TEST_DATA.md](TEST_DATA.md) 的資料貼到網站「建立計畫」頁面，約一分鐘就能測試計畫、進度與練習。AI 出題另需使用者自己的 Gemini API 金鑰。

## 功能與草稿對照

| 草稿構想 | 網站操作 | 目前範圍 |
| --- | --- | --- |
| 從 Notion、課本、講義、掃描筆記取得內容 | 在「建立計畫」貼入文字重點；來源網址可選填 | 不連接 Notion，也不直接讀取 PDF、照片或掃描件；先自行整理或 OCR 成文字 |
| 根據教材和時間安排課程 | 填主題、重點、每日分鐘數、一週天數，按「產生本週計畫」 | 以固定規則排程：從今天起連續安排指定天數，最後一天回顧與測驗；AI 目前只用於出題 |
| 每週課表與 Google Calendar | 在「每週安排」看任務，下載 `.ics` 檔後匯入行事曆 | 匯出的是全天事件，預計分鐘數寫在描述中；不直接寫入 Google 帳號 |
| 自動出題與錯題重複複習 | 「練習測驗」可做筆記自我檢查；貼自己的金鑰可請 Gemini 出三題 | 「待複習」排序只作用於筆記自我檢查題；Gemini 題目以文字顯示，不會自動評分或記入進度 |
| 學習進度與家長查看 | 勾選任務、標記筆記題，再看「學習進度」的兩種摘要 | 家長／老師視角是同一瀏覽器中的摘要，沒有登入、通知或跨裝置同步 |

## 操作流程

1. **建立計畫：** 填「科目或主題」、「教材重點」、每日可讀書分鐘數和一週讀書天數。重點可分行貼入；來源網址可留空。按「產生本週計畫」後，網站會建立 1–7 個任務。再次產生計畫會覆蓋原任務、重設練習統計和待複習清單。
2. **執行任務：** 在「每週安排」查看日期、主題和預計時間，完成後勾選「已完成」。進度百分比是已完成任務數 ÷ 總任務數。例如五個任務完成一個，顯示 20%。
3. **匯入行事曆：** 按「下載 Google Calendar 可匯入檔」取得 `讀書計畫.ics`，再到 Google Calendar 的設定中選「匯入與匯出 → 匯入」。匯入後是全天事件；想指定實際時段，請在行事曆手動修改。
4. **練習重點：** 「重點練習」會用教材的前幾行產生自我說明題。先回答，再展開筆記提示；按「答對」或「待複習」。待複習的題目下次進入練習頁時排在前面，答對後移出待複習清單。
5. **使用 Gemini：** 在「自備 Gemini 金鑰出題」貼自己的金鑰，網站會將目前主題和教材重點送到 Gemini，要求產生三題選擇題及解析。生成內容只顯示在頁面，未保存成題庫，也不影響上述練習統計。
6. **查看摘要：** 「學習進度」顯示任務完成比例、筆記練習次數及待複習題數；右側顯示同一份資料的家長／老師摘要。

## 學生自備 Gemini API 金鑰

學生可在 [Google AI Studio 的 API Keys 頁面](https://aistudio.google.com/api-keys) 建立自己的金鑰，確認專案的免費或付費方案，再貼到網站。程式使用 `gemini-2.5-flash` 的 `generateContent` API。金鑰只留在本次開啟頁面的輸入欄位，不寫入專案程式碼或瀏覽器 `localStorage`；重新整理或離開頁面後需要重新貼。教材重點會直接從學生瀏覽器送往 Google Gemini API。

每把金鑰都對應 Google 專案，額度與費用依專案方案而定。免費方案在額度內不收費，到達限制可能暫時無法呼叫；只有使用者自行啟用付費方案時，才依該專案的計費設定付費。「貼上金鑰」本身不代表一定會產生費用。使用者可在 [AI Studio](https://aistudio.google.com/) 檢查方案和使用量；模型可用性、免費額度及價格以 [Google 官方資訊](https://ai.google.dev/gemini-api/docs/pricing)為準。

**金鑰安全界線：** GitHub 儲存庫沒有任何人的金鑰，但瀏覽器直接呼叫 API 時，金鑰會出現在該使用者瀏覽器的網路請求中，瀏覽器擴充功能和共用電腦也可能接觸到。此模式適合知悉這項限制的課堂示範。Google 對正式產品建議使用伺服器端代理保護金鑰，詳見 [API 金鑰說明](https://ai.google.dev/gemini-api/docs/api-key)。不要把付費金鑰貼在共用電腦，不要提交金鑰到 GitHub；疑似外洩時在 AI Studio 更換或停用。

## 部署與更新

本專案的 GitHub 遠端是 `peculab/ClaudeClass`，發布來源應使用 `main` 分支的根目錄。到儲存庫 **Settings → Pages → Build and deployment**，選 **Deploy from a branch → main → /(root)** 並儲存。網站預期網址是 `https://peculab.github.io/ClaudeClass/`；請以 Pages 設定頁實際顯示的網址為準。[GitHub Pages 官方操作說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

修改 `index.html`、`style.css`、`app.js` 或本文後，將變更 commit 並 push 到 `main`，GitHub Pages 會依發布設定更新。直接開啟本機 `index.html` 可測試建立計畫、筆記練習、進度與 `.ics` 下載；Gemini 出題請在發布後的 HTTPS 網站用自己的金鑰實測。`ref/` 是本機課堂原始參考資料，已加入 `.gitignore`，不隨公開網站發布。

## 資料與已知限制

網站將主題、教材文字、來源網址、任務和筆記練習記錄保存在目前瀏覽器的 `localStorage`。換瀏覽器或裝置、使用無痕模式、清除網站資料後，進度無法恢復。家長視角沒有獨立權限，必須在同一瀏覽器查看；教材文字也不會上傳到本專案的伺服器，但使用 Gemini 出題時會送到 Google API。請不要貼入個資或不宜分享的教材。

排程沒有避開週末、考試日或已存在的行事曆活動，也沒有 AI 自動調整；同一週重新建立計畫會重設完成紀錄。筆記題目前只取教材前幾行，待複習資料依這些行的位置記錄。這些都是最小示範範圍，不能當作完整的學習管理系統。

如果 AI 出題失敗，先確認主題及教材至少有 20 字、金鑰屬於可使用 Gemini 的專案、該專案有剩餘額度，並在 GitHub Pages 的 HTTPS 網址重試。頁面會顯示簡要的連線或 HTTP 狀態訊息；它不會顯示 Google 回傳的完整錯誤內容，以免將敏感資訊呈現在畫面上。若需要學生登入、跨裝置同步、家長獨立查看或更安全的金鑰使用方式，下一階段需加入資料庫、帳號與伺服器端權限設計。
